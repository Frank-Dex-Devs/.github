## Our stack

We don't mention technologies to impress. We mention them because they're the reason our work performs the way it does.

```
Backend      Laravel 11  ·  PHP 8.3  ·  Livewire 4
Frontend     Tailwind CSS v4  ·  Alpine.js  ·  Flux UI
Database     MySQL  ·  PostgreSQL  ·  Redis
Payments     M-Pesa Daraja  · Kopokopo · Stripe  ·  Paystack  ·  Flutterwave
Testing      Pest PHP
Deployment   Laravel Forge  ·  GitHub Actions  ·  CI/CD
```

**Why Livewire over React/Vue?** Every page we ship is server-rendered. Real HTML in the response. No hydration. No JS bundle blocking the parser. Google sees your content immediately — and so does every other crawler. SEO isn't an afterthought in our stack; it's the architecture.

